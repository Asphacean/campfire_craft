<objective>
Retire every Phase 1 blocker that can stop the server before it exists: no Java 8 on this box, a modpack download that CurseForge may refuse to serve to a script, and a home connection that may be behind CGNAT (which invalidates SRV-04 entirely).

Purpose: the next plan installs and boots the pack. It must not discover mid-boot that the JVM is wrong, the zip is an HTML error page, or that no port forward can ever work. CONTEXT.md makes the CGNAT check the first thing that happens; RESEARCH.md Pitfall 1 makes the CurseForge download the single highest-risk step in the phase.
Output: a bootstrapped host (Temurin 8 + zstd + rcon-cli), a verified pack zip on disk, and one env file holding every operator-supplied fact the rest of the phase reads.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CurseForge CDN / API → local disk | A ~318 MB third-party archive crosses onto the host and is later unpacked and executed as server code |
| Adoptium apt repo / GitHub releases → system paths | Third-party binaries installed with sudo into `/usr/lib/jvm`, `/opt`, `/usr/local/bin` |
| Operator (human) → server.env | Untrusted-by-default free text (domain, WAN IP, nicknames, API key) lands in a file every later script sources |
| server.env → git → any future remote | Secrets could leave the machine if committed |
