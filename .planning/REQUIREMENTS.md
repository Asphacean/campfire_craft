# Requirements: RLCraft Private Server

**Defined:** 2026-08-27
**Core Value:** A friend downloads the launcher, registers a nick + password, presses Play — and ends up on the RLCraft server with no manual setup.

## v1 Requirements

### Game Server (SRV)

- [ ] **SRV-01**: RLCraft Server Pack 2.9.3 (Forge 1.12.2-14.23.5.2860) runs on the Pi 5 under Java 8 (Temurin aarch64) in offline-mode
- [ ] **SRV-02**: Server starts on boot and restarts on crash (systemd `Restart=on-failure`)
- [ ] **SRV-03**: World is backed up on a schedule with rotation, and a restore from backup has been tested once
- [ ] **SRV-04**: Server is reachable from the internet on TCP 25565 via domain (port forward + DDNS/static; CGNAT verified absent)
- [ ] **SRV-05**: Server holds ≥ 15 TPS with 3 concurrent players after JVM/config tuning (heap ≤ 8 GB) — verified by a real load test

### Authentication (AUTH)

- [x] **AUTH-01**: Player can register an account (nick + password) from the launcher; nick uniqueness enforced, password stored hashed (argon2/bcrypt)
- [x] **AUTH-02**: Player can log in from the launcher and receive a short-lived session token
- [ ] **AUTH-03**: Launcher remembers the session (token, never the plaintext password) so the player is not asked for a password every launch
- [x] **AUTH-04**: Game server rejects any join whose token is missing or invalid (server-side auth-gate Forge mod validating against the auth service over loopback); vanilla clients cannot join under a registered nick
- [x] **AUTH-05**: Client-side auth mod ships in the modpack and transmits the launcher-provided token on join

### Client Distribution (DIST)

- [ ] **DIST-01**: File server (Caddy, HTTPS with auto-TLS) serves the client modpack files and a manifest listing path + sha256 for every managed file (mods/, config/, …)
- [ ] **DIST-02**: Manifest is regenerated by a single command/script after the operator changes mods/configs
- [ ] **DIST-03**: Minecraft client jar, libraries and assets are downloaded from Mojang's official servers, never mirrored; mod jars are served only if their license permits, otherwise fetched from CurseForge
- [ ] **DIST-04**: Server exposes a status endpoint (online/offline, player count) consumable by the launcher

### Launcher (LNCH)

- [ ] **LNCH-01**: Launcher has a single screen: nick, password, Register/Login, RAM slider (3–10 GB, sensible default), Play button
- [ ] **LNCH-02**: On Play, launcher diffs local files against the manifest and downloads only changed/missing files; deletes stale managed files; never touches saves/options.txt/servers.dat
- [ ] **LNCH-03**: Launcher downloads a Java 8 runtime automatically if absent: Adoptium for Windows x64 and macOS Intel, Azul Zulu for macOS Apple Silicon; never uses system Java
- [ ] **LNCH-04**: Launcher installs/constructs the Forge 1.12.2 client (version json merge, libraries, natives, assets) and launches with the chosen RAM, injecting the auth token and auto-connecting to the server
- [ ] **LNCH-05**: Launcher shows progress (step + file count/bytes) during download and launch
- [ ] **LNCH-06**: Failures show a human-readable message (wrong password, server unreachable, disk full, Java download failed) and point to a local log file
- [ ] **LNCH-07**: Launcher shows server status (online/offline, player count) from DIST-04
- [ ] **LNCH-08**: Launcher checks for its own new version on startup and updates itself (Tauri updater)

### Build & Release (REL)

- [ ] **REL-01**: GitHub Actions builds Windows x64 installer and macOS universal/arm64+x64 .app on every tag
- [ ] **REL-02**: macOS build is unsigned; README/first-run instructions explain the one-time Gatekeeper bypass (`xattr -cr` / Open Anyway)
- [ ] **REL-03**: Launcher works on Apple Silicon (LWJGL2 natives / Rosetta path verified on real hardware)

## v2 Requirements

### Cosmetics & Ops

- **SKIN-01**: Player skins for offline-mode (requires Drasl/authlib-injector — conflicts with current auth design)
- **OPS-01**: Web admin panel / RCON dashboard
- **AUTH-06**: Password reset flow (operator resets manually via CLI in v1)
- **REL-04**: Signed + notarized macOS build (Apple Developer account)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Microsoft/Mojang login | Friends without license; own auth chosen |
| Linux launcher build | No Linux players |
| Multiple accounts per install | One person per machine |
| News feed / theming in launcher | "Minimalist" was explicit |
| Offline/singleplayer mode in launcher | Launcher exists only to join this server |
| Anti-grief / moderation / ranks | Closed friend group |
| Modpack editing UI | Launcher ships the exact server pack |
| Docker for the game server | Bare systemd is simpler and faster on Pi; Docker adds nothing here |
| Crash telemetry pipeline | Local log + paste in Discord suffices |
